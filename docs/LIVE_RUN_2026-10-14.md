## Bugs the live runs exposed — all fixed and covered by tests

1. Requested runs did not pass the database's actor types to page scoring → run stopped before reading pages. Fixed in `query_generation.py`; test added.
2. Hub lookup used an untyped `:topic_id IS NOT NULL` (3 more in `fact_reads.py`) — fails under the psycopg 3 driver. Cast explicitly; checked under psycopg 3.
3. My new "verified by agent" step was missing from `promote.py`'s ordered-step check → creation refused. Fixed; new database integration test creates an accepted actor and asserts Verified, the labelled event, and no review item.
4. Pre-existing: event duplicates were saved with band `duplicate`, which the database rejects, so the whole batch of event candidate rows failed to save (events themselves were promoted). Fixed in `store.py`; test added.
5. A failed request run recorded $0 spend. Now records the search run's real cost and links it.

The three failed actor attempts cost $4.90 of the $8.55.
